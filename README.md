# SODA-CitrON

Code from the paper [SODA-CitrON: Static Object Data Association by Clustering Multi-Modal Sensor Detections Online](https://arxiv.org/abs/2602.22243), accepted for [ISIF FUSION 2026](https://www.ntnu.edu/fusion2026).

## Example installation

1. Clone this repo and navigate into it
2. Create venv: `python -m venv .venv`
3. Activate venv: `source .venv/bin/activate`
4. Install example code: `pip install .[example]`
5. Try it out in `example/example.ipynb`

## Installation as a package

`pip install git+https://github.com/th3sh3ph3rd/SODA-CitrON.git`
